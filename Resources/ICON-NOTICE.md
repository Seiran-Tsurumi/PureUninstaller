# Icon notice

The application icon was provided by the user as `StarLogo.png` (originally a 1280×1280 JPEG, normalized to PNG in the project).

Adaptations made for macOS:

- removed the “豆包 AI 生成” watermark in the lower-right corner;
- applied a transparent rounded-square mask following the original artwork silhouette;
- trimmed the white JPEG fringe;
- generated the full 16–1024 px `.iconset` and compiled `AppIcon.icns`.

The original character artwork and color palette are otherwise unchanged.
